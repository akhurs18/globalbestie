# Product seed — 100 listings

`product-import-100.json` is 100 review-ready product **drafts** for the
storefront, generated by `scripts/generate-product-seed.mjs`.

## What's in it

100 real luxury products across the 5 store categories:

| Category | Count |
| --- | --- |
| Handbags | 28 |
| Shoes | 24 |
| Makeup | 26 |
| Fragrance | 12 |
| Accessories | 10 |

Each listing has: title, brand, category, premium description, a realistic
USA retail price (USD), a per-category shipping estimate (PKR), variants hint,
and the official brand `source_url`. The storefront computes the final PKR
price from these using your pricing formula and rounds it to a clean luxury
figure.

## How to import

1. Open the portal → **Products** tab.
2. Use the **import** control and pick `seeds/product-import-100.json`.
3. All 100 arrive as **drafts** (`product_status: "draft"`) — nothing goes
   live until you publish each one.

## ⚠ Before publishing — two required steps per product

These are intentionally left for your review (they can't be done safely
without you):

1. **Replace the placeholder image.** Every listing ships with a category
   placeholder, not the real product photo — brand sites block automated
   image fetching and their CDN images break when hotlinked. Each draft's
   `authenticity_note` flags this with the brand URL. Use the portal's
   per-product image fetch/upload (it re-hosts to Supabase via
   `downloadAndStoreImage`, which fixes hotlinking) to drop in the real photo.
2. **Verify the USA retail price.** Prices are accurate-tier but not
   live-checked — confirm the current retail before publishing.

## Regenerating

```
node scripts/generate-product-seed.mjs
```

The script validates structure (unique ids, required fields, valid
categories, positive prices) and aborts on any problem, so the output is
always import-clean.
